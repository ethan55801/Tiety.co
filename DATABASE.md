# Data and storage inventory

This website is static. There is no database server, schema, table, migration, customer record, or database credential to export or clone.

All website content is stored in `dist/index.html`. Styling, scripts, and artwork are in `dist/assets/`. These files are the complete application source.

The project brief is assembled in browser memory and downloaded as a text file. Its name, email, selected service, and description are not sent to Tiety or stored by this website. Closing the page discards the form state, subject to the browser's own normal autofill or session behavior.

The website writes only the animation preference `tiety-motion-paused` to browser localStorage. It does not use analytics, tracking cookies, external fonts, or an application API. Hosting providers may process ordinary web request information under their own policies.

GitHub Pages serves static files. Receiving enquiries or keeping customer records would require a separately configured backend and an agreed contact/privacy workflow. This project does not claim that those features exist.
